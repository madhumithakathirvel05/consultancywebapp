# Consultancy Web App

A responsive, user-friendly consultancy web application designed to help users explore consultation services, submit enquiries, request appointments, and connect with consultants easily.

## Features
- Responsive and mobile-friendly design
- Service listings and consultation information
- Online enquiry and appointment request forms
- Google Apps Script integration for collecting form submissions in Google Sheets
- Direct call and WhatsApp contact options
- Privacy Policy and Terms & Conditions pages
- Clean, professional user interface
- Blue, purple, and white colour theme

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- GitHub for version control and collaboration

## Deployment
The frontend can be hosted using GitHub Pages or another static website hosting platform. Google Apps Script is deployed separately as a web app to process form submissions.

## Purpose
To provide a convenient online platform for discovering consultancy services, making enquiries, and requesting appointments through a simple and accessible interface.
